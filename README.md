# Mon audit budget

Application web d'audit budgétaire et de stratégie d'épargne, **100 % côté navigateur** : les relevés, avis d'impôt et fiches de paie sont lus sur l'appareil de l'utilisateur et ne sont jamais envoyés.

- Accès : https://camilbounader.github.io/audit-budget/
- Installation sur iPhone : Safari → Partager → « Sur l'écran d'accueil »
- Installation sur Android : Chrome → ⋮ → « Installer l'application »

Ce dépôt ne contient que le code de l'application, aucune donnée personnelle.

Lecture PDF : [pdf.js](https://github.com/mozilla/pdf.js) (Mozilla, licence Apache 2.0, voir `vendor/PDFJS-LICENSE.txt`).

Outil pédagogique : ne constitue pas un conseil en investissement personnalisé ni un conseil fiscal.
